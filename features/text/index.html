기능 지원 무료
WHERE TO FIND IT

Edit → Effects → Titles → Text

01

다빈치에서 사용하는 방법

  1. 01

    Effects → Titles에서 Text를 찾습니다.

  2. 02

    상위 비디오 트랙에 배치합니다.

  3. 03

    Inspector에서 글자·크기·위치를 편집합니다.

✳알아두면 좋은 점
자막 트랙(Subtitle)과 일반 텍스트 타이틀은 용도가 다릅니다.
