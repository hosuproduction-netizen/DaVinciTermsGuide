Tracker

움직이는 얼굴이나 물체를 따라 Window 영역을 이동시킵니다.

기능 지원 무료
WHERE TO FIND IT

Color → Tracker

01

다빈치에서 사용하는 방법

  1. 01

    Color 페이지에서 Window로 영역을 지정합니다.

  2. 02

    Tracker를 열고 앞뒤로 추적합니다.

  3. 03

    움직임을 확인하고 필요한 구간을 보정합니다.

✳알아두면 좋은 점
기존 앱의 자동 추적과 비교할 때 수동 보정이 필요할 수 있습니다.
