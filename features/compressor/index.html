목소리 크기 차이 줄이기

Compressor / Dynamics

큰 소리는 줄이고 작은 소리와의 차이를 완화하는 오디오 다이내믹 도구입니다.

기능 지원 무료
WHERE TO FIND IT

Fairlight → Mixer → Dynamics → Compressor

01

다빈치에서 사용하는 방법

  1. 01

    Fairlight 페이지에서 해당 트랙을 선택합니다.

  2. 02

    Mixer의 Dynamics를 엽니다.

  3. 03

    Compressor를 켜고 Threshold·Ratio 등을 조절합니다.

✳알아두면 좋은 점
컴프레서는 정규화와 다르게 시간에 따른 음량 변화를 제어합니다.

02
