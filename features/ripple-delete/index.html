빈 공간 없이 삭제

Ripple Delete

클립을 지우면서 뒤쪽 클립을 당겨 빈 공간을 없앱니다.

기능 지원 무료
WHERE TO FIND IT

Edit → 클립 선택 → Ripple Delete

01

다빈치에서 사용하는 방법

  1. 01

    타임라인에서 지울 클립을 선택합니다.

  2. 02

    Ripple Delete 명령을 사용합니다.

  3. 03

    주변 트랙과 삭제 범위가 맞는지 확인합니다.

✳알아두면 좋은 점
일반 Delete는 타임라인에 빈 구간을 남길 수 있습니다.
