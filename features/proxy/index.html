편집용 가벼운 파일 만들기

Proxy Media

고해상도 원본 대신 가벼운 프록시 파일로 부드럽게 편집합니다.

기능 지원 무료
WHERE TO FIND IT

Media Pool → 클립 우클릭 → Generate Proxy Media

01

다빈치에서 사용하는 방법

  1. 01

    Media Pool에서 원본 클립을 선택합니다.

  2. 02

    Generate Proxy Media를 실행합니다.

  3. 03

    프록시 연결 상태를 확인하고 편집합니다.

✳알아두면 좋은 점
프록시 파일과 최종 출력에 사용하는 원본 파일을 구분하세요.

02
