01

다빈치에서 사용하는 방법

  1. 01

    Project Manager에서 프로젝트를 만듭니다.

  2. 02

    Media Pool에서 새 타임라인을 만듭니다.

  3. 03

    한 프로젝트 안에 여러 타임라인을 정리해 봅니다.
