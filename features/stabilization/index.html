흔들리는 영상 안정화

Stabilization

촬영 중 발생한 영상 흔들림을 분석해 부드럽게 보정합니다.

기능 지원 무료
WHERE TO FIND IT

Edit → Inspector → Stabilization (또는 Color → Tracker)

01

다빈치에서 사용하는 방법

  1. 01

    흔들리는 클립을 선택합니다.

  2. 02

    Inspector의 Stabilization 항목을 엽니다.

  3. 03

    분석을 실행한 후 결과를 확인합니다.

✳알아두면 좋은 점
결과가 과도하게 잘리거나 왜곡되면 설정을 완화합니다.
