Zoom

클립 화면의 크기를 키우거나 줄입니다.

기능 지원 무료
WHERE TO FIND IT

Edit → Inspector → Video → Transform → Zoom

01

다빈치에서 사용하는 방법

  1. 01

    클립을 선택하고 Inspector를 엽니다.

  2. 02

    Video → Transform에서 Zoom 값을 조정합니다.

  3. 03

    움직임이 필요하면 다이아몬드 아이콘으로 키프레임을 추가합니다.

✳알아두면 좋은 점
다빈치의 Zoom은 프리미어·캡컷의 Scale과 비슷한 역할입니다.
